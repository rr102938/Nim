# Nim Reinforcement Learning AI (CS50 AI)

## What it does
* This is a Python program that implements a Q-learning reinforcement learning agent to play the game of Nim.
* The AI learns optimal strategies by playing thousands of training games against itself, updating its Q-values based on rewards and future outcomes, and eventually mastering how to beat human opponents.

## Technologies Used
* Python
* Q-Learning (Reinforcement Learning algorithm)
* Git / GitHub

## How to Run It
* Make sure you have Python installed on your computer.
* Run the script interactively or add a main execution loop to train and play         against the AI:
* "```bash"
* python nim.py
* Train the AI model and play a game of Nim against it by choosing your pile and object count.
